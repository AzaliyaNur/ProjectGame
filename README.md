# План по разработке

*Как пример используется: https://github.com/akilkalpittifaki/a--algorithm*

 «Пятнашки» — это головоломка, состоящая из квадратного поля с 15 пронумерованными фишками и одной пустой клеткой. Цель — расположить числа по порядку, от 1 до 15, передвигая их внутри поля за минимальное количество ходов.
1. ## Логика поля (Board/Board)
   Хранит состояние игрового поля 4×4, управляет перемещением плиток и проверяет победу.
2. ## Решение паззла (Solver/AStarSolver)
   Находит кратчайшее решение головоломки с помощью алгоритма A*
3. ## Генератор (Generator/PuzzleGenerator)
   Генерирует случайные решаемые начальные конфигурации для новой игры.
4. ## Пользовательский интерфейс (UI/PuzzleUI)
   Отвечает за визуальное отображение игры и взаимодействие с игроком.
5. ## GameController (Utils/GameController)
   Центральный «мозг» проекта. Связывает все модули, обрабатывает события и управляет потоками.
