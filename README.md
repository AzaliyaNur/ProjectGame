# План по разработке

*Как пример используется: https://github.com/akilkalpittifaki/a--algorithm*

 «Пятнашки» — это головоломка, состоящая из квадратного поля с 15 пронумерованными фишками и одной пустой клеткой. Цель — расположить числа по порядку, от 1 до 15, передвигая их внутри поля за минимальное количество ходов.
1. ## Ядро игры (логика поля) - Азалия
   - Класс Board (4×4 массив)
   - Методы Move(direction), IsSolved(), GetEmptyPos()
   - Проверка корректности ходов
2. ## A* солвер (самый важный модуль) - не занято
   - Реализация A* алгоритма
   - Очередь с приоритетом (Min-Heap)
   - Манхэттенская эвристика
   - Доп. эвристика: Manhattan + Linear Conflict для лучшей производительности
3. ## Генератор и проверка чётности - не занято
   - Генератор случайной перестановки
   - Алгоритм проверки чётности (решаема ли позиция) — если нерешаема, меняем два последних элемента местами
   - Интерфейс для передачи начального состояния в солвер
4. ## Пользовательский интерфейс - не занято
   - Отрисовка сетки 4×4
   - Обработка кликов по плиткам (или клавиш WASD/стрелки)
   - Кнопки: «Новая игра», «Решить», «Шаг вперёд»
   - Отображение текущего счёта ходов
   - Прогресс-бар или статус «Думаю...» во время работы A*
5. ## Интеграция, анимация и отладка - не занято
   - Соединяет модули 1-4 в рабочий проект
   - Реализует пошаговую анимацию решения (через Timer или async/await + Thread.Sleep)
   - Обрабатывает состояния игры (ожидание хода / анимация / блокировка кнопок)
   - Пишет простой логгер (Console или файл)
   - Отвечает за финальную сборку и демо
